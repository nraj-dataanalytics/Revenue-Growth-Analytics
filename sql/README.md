# 📄 SQL -- Revenue Growth Management Data Model

## Overview

This folder contains all SQL scripts used to build the **Revenue Growth
Management (RGM) analytical data warehouse** for this project.

The objective of the SQL layer is to: - Transform a **generic retail
transaction dataset (Superstore)** into a **fictional tobacco company
dataset** - Design a **star schema** suitable for pricing, trade, and
competitive analysis - Provide a **stable, analytics-ready backend** for
R, Power BI, and executive reporting

All transformations are implemented in **MySQL** using **DBeaver**.

------------------------------------------------------------------------

## Source Dataset and Business Re-Framing

### Original Dataset

-   Dataset: **Superstore**
-   Nature: Generic retail transactional data
-   Grain: Order-level line items

### Core Metrics Preserved

The following metrics are preserved exactly as-is from the source
dataset: - Sales\
- Profit\
- Quantity\
- Discount\
- Shipping Cost\
- Transaction dates and geography

These metrics are treated as **sell-in (wholesale) performance
measures**, consistent with RGM use cases.

------------------------------------------------------------------------

## Fictional Tobacco Dataset Simulation

To align the dataset with a **Revenue Growth Management use case in the
tobacco industry**, the Superstore dataset was **systematically
re-framed** using controlled, transparent transformations.

> **Important:**\
> This project does **not** use any real PMI, tobacco brand, or
> confidential data.\
> All tobacco-related entities are **fully fictional and simulated for
> analytical purposes only**.

### Product Re-Mapping

Superstore product categories were mapped to tobacco product families:

  Superstore Category   Simulated Tobacco Product Family
  --------------------- ----------------------------------
  Office Supplies       Combustible Products
  Technology            Heated Tobacco Products
  Furniture             Oral Nicotine Products

Additional simulated product attributes include: - Brand tier (Premium /
Core / Value) - Nicotine format - Pack size (10-pack, 20-pack,
30-pack) - Synthetic product variant names

Original product brand names were intentionally **removed** to avoid
retail bias and to reflect FMCG/tobacco modeling standards.

------------------------------------------------------------------------

### Channel Simulation

Superstore customer segments were mapped to realistic tobacco sales
channels:

  Superstore Segment   Simulated Channel
  -------------------- -------------------
  Consumer             Retail
  Corporate            Key Accounts
  Home Office          E-Commerce

This enables channel-level pricing and trade analysis consistent with
RGM frameworks.

------------------------------------------------------------------------

### Wholesaler Simulation

The Superstore dataset does not contain wholesalers.\
To reflect real-world tobacco distribution structures:

-   Synthetic wholesalers were generated by **country × channel**
-   Wholesalers were tiered into:
    -   T1 -- National Distributor
    -   T2 -- Regional Distributor
    -   T3 -- Local Wholesaler

This allows analysis of: - Channel dependency - Wholesaler concentration
risk - Trade investment effectiveness

------------------------------------------------------------------------

### Pricing Simulation

Because Superstore does not include list prices:

-   **Net invoice price** was derived as:\
    `Sell-in Revenue ÷ Shipment Volume`
-   **List price** was reverse-calculated using discount rates
-   Weekly price changes were tracked using window functions
-   Price strategy labels were assigned based on product tier and
    channel

------------------------------------------------------------------------

### Trade Incentive Simulation

Discounts from Superstore were re-interpreted as **trade incentives**,
enabling: - Trade spend calculations - Incentive type classification -
Compliance flagging

------------------------------------------------------------------------

### Competitor Pricing Simulation

No competitor data exists in Superstore.\
To enable competitive benchmarking:

-   Three fictional competitors were introduced
-   Competitor prices were derived from list prices using:
    -   Positioning multipliers (Value / Mainstream / Premium)
    -   Deterministic noise to ensure variability and reproducibility

------------------------------------------------------------------------

## Schema Design

The warehouse follows a **weekly star schema** optimized for RGM
analytics.

### Dimension Tables

-   `dim_product`
-   `dim_country`
-   `dim_region`
-   `dim_channel`
-   `dim_wholesaler`
-   `dim_date_week`

### Fact Tables

-   `fact_shipments_weekly`
-   `fact_price_weekly`
-   `fact_trade_incentives_weekly`
-   `fact_competitor_price_weekly`
